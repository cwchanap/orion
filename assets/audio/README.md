# Orion audio

## Background music (HPA-168)

The four music tracks are original ElevenLabs Music v2 generations made from
project-authored prompts, without reference recordings. They are intended for
HPA-417's playback integration. Each is a 20-second, 22,050 Hz, 16-bit mono
PCM WAV, 882,044 bytes; the four total 3,528,176 bytes.

| File | Intended use |
| --- | --- |
| `music_map.wav` | Quiet navigation and menus |
| `music_build.wav` | Thoughtful preparation |
| `music_wave.wav` | Restrained combat pulse |
| `music_boss.wav` | Higher-tension boss ambience |

`music_provenance.json` records the prompts, model, generation IDs, source
checksums and chosen start time. Each 30-second MP3 was decoded to mono PCM
with FFmpeg 8.1.2; the retained decoded takes are in the gitignored
`assets/audio/music_sources/` directory. Keep a private backup of these files.
With those takes present, `python3 scripts/generate_music.py` checks their hashes
and reproduces the masters offline using a two-second overlap crossfade and a
peak target of 0.16 full scale (about -15.9 dBFS). The source recordings cannot
be regenerated byte-for-byte from prompts, and the script does not read or alter
the sound-effect sources. Run the following to check the shipped files and, when
source takes are available, their offline reproduction:

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
```

The generated tracks are subject to the generating account's
[ElevenLabs Music Terms](https://elevenlabs.io/music-terms); the account's
rights for public repository distribution and game release still need to be
confirmed. Automated waveform checks do not establish musical quality,
masking, or native-player gaplessness. Listen on representative iOS and Android
devices in each context, with combat effects and across repeated loop seams,
before accepting the tracks.

## Feedback sounds

`confirm.wav`, `clear.wav`, `victory.wav`, and `defeat.wav` are project-owned
original one-shot sound effects generated by `scripts/generate_feedback_audio.py`.
The generator uses only Python's standard library and 16-bit mono PCM synthesis.

## Sources and reproducible mastering

`sources/provenance.json` records each original prompt, model settings, flow,
node/session/generation IDs, download checksum, decoded-source checksum, and
final duration/peak target. The 17 `sources/*.wav` files are the full generated
takes decoded once from ElevenLabs MP3 to mono PCM with FFmpeg 8.1.2. They retain
the generated audio before mastering; do not replace them during regeneration.
No existing recording or third-party reference sample was supplied to the model.

`sources/` is gitignored and **not tracked in this public repository**: the
Sound Effects terms restrict making generated output available as isolated audio
files. Authorized maintainers obtain `sources/` (the 17 WAVs and
`provenance.json`) from the project owner's private storage and place it at
`assets/audio/sources/` before regenerating.

From the repository root:

```sh
python3 scripts/generate_feedback_audio.py
python3 -m unittest discover -s scripts -p 'test_*.py'
```

Regeneration is offline and Python stdlib only: validate source checksums/format,
soften hiss with a 6.5 kHz low-pass, remove DC, trim leading silence with 3 ms
pre-roll, crop/pad to the table's duration, apply 3 ms attack / 25 ms release
fades to zero, and normalize to the listed peak. It validates every combat
source before writing any output. Running it rebuilds all 21 files byte for byte;
it does not call ElevenLabs or require FFmpeg. Fresh AI generation is stochastic
and spends credits, so it is not the regeneration path.

The 21 sound-effect WAV paths are registered individually in `pubspec.yaml`.
Neither this README nor the source/provenance directory ships in the app bundle.

## Licensing and remaining review

The original four cues are project-owned procedural audio. The new pack uses
project-authored prompts and ElevenLabs-generated output, subject to the account's
agreement; it is not represented as CC0, public domain, or unrestricted stock.
[ElevenLabs' Sound Effects terms (Exhibit 4)](https://elevenlabs.io/creative-terms)
allow embedding output with other material in games, subject to the applicable
plan, and restrict making isolated audio files or sound libraries available.
[Commercial use requires an eligible plan](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform).
The MCP does not expose proof of this account's plan; the generating account
owner has confirmed that the account's agreement permits distributing the 21
mastered WAVs as individually tracked files in this public repository, while
the raw source takes in `sources/` stay private. Distribution and commercial
use remain subject to the generating account's agreement; inclusion in this
repository does not grant unrestricted redistribution rights.

Automated checks cover regeneration, existing-cue preservation, WAV format,
duration, non-silence, peak headroom, and zero-valued endpoints. Distinctness,
pleasantness and rapid repetition at 1x/3x still need listening on a representative
mobile device with HPA-416's playback integration; numeric checks do not prove
that acceptance item.
